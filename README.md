# 扒人 · 六路采集工具

> 输入一个人名/主题名，6 路并行采集信息，父进程汇总后直接呈现。

## 一句话用法

```
> 六路采集 Elon Musk
> 六路采集 特朗普
```

## 采集维度

| # | 维度 | 说明 |
|---|------|------|
| 1 | 著作/论文 | 学术出版、研究报告、专栏文章 |
| 2 | 播客/访谈 | 播客节目、视频访谈、公开演讲 |
| 3 | 社交媒体 | 小红书/B站/知乎/抖音/微博内容分析 |
| 4 | 批评者视角 | 争议、质疑、反驳观点 |
| 5 | 决策/成就记录 | 关键决策、重大事件、荣誉奖项 |
| 6 | 时间线 | 全量信息的时间排序 |
